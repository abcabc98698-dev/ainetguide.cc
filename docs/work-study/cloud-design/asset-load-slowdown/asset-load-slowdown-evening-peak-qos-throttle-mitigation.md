# 素材加载缓慢：晚高峰拥塞对抗与 QoS 限速穿透策略

## UDP 丢包整流与实时交互 QoS 保障

对于包含音频或高频数据交互的 素材加载缓慢 业务，公网丢包会导致乱序重传与应用层丢帧。通过在专线两端建立带 FEC 前向纠错的多路复用隧道，可彻底抚平公网物理波动。

```text
[公网传输] 乱序抖动 35ms ──> 接收端抖动缓冲区溢出 ──> 客户端报错异常
[专线隧道] 内网物理直连 ──> 抖动标准差 < 1.8ms ──> 达成指标: < 90ms (实时上屏)
```

## 拥塞排障问答

### Q: 多人协同编辑 Figma 画布时经常延迟拖影、提示正在重新连接？
Figma 采用 WebSocket 同步多人鼠标与矢量图层，公网丢包会导致画布重连。配置专线分流可实现 30ms 极低协同延迟。
