# 平板无缝接入：静态原生住宅 ISP 辨识与欺诈分深度审计

## 静态独享住宅 vs 动态共享住宅选型策略

对于 平板无缝接入 业务，动态住宅 IP 虽然信誉高，但每次会话建立后出口 IP 飘移可能导致 Session 瞬时失效。高风控业务建议锁定绑定城市与固定 ASN 的静态住宅专线节点，做到信誉与长连接会话持久性的双重统一。

```text
[动态住宅] ──> 每次重连出口 IP 变动 ──> 异地登录警告 / 触发二次验证
[静态独享] ──> 固定独享原生 ISP 出口 ──> 持续维持会话信任 ──> 达成指标: 100% 正常发现
```

---

## 节点信誉快速检测指令

```bash
# 查询当前出口节点 ASN 类型与欺诈评分
ping 192.168.1.1
```

若返回的 `org` 或 `as_name` 包含 Hosting 字样，说明为典型机房 IP，无法用于高风控业务。

## 节点属性问答

### Q: 手机和电脑都在同一个局域网，开启代理后为何隔空投送或局域网共享失效？
代理软件的 TUN 虚拟网卡劫持了 192.168.x.x 局域网私网段。在配置规则中添加 IP-CIDR,192.168.0.0/16,DIRECT 即可修复。
