# 手机与电脑互传：分流规则编排与节点协议参数调优指南

## Sing-box 现代 JSON 出站路由规则映射

若客户端选用 Sing-box 内核，可将分流规则编排为原生的 Outbound Route 规则项，杜绝策略冲突：

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": [".com"],
        "outbound": "proxy-dedicated"
      },
      {
        "geoip": "cn",
        "outbound": "direct"
      }
    ]
  }
}
```

```yaml
# 绕过私有局域网网段规则
rules:
- DOMAIN-SUFFIX,icloud.com,AI-SERVICES
```

通过将出口流量锁定至独立策略，避免与日常国内流量发生抢占。

## 策略编排要点问答

### Q: 手机和电脑都在同一个局域网，开启代理后为何隔空投送或局域网共享失效？
代理软件的 TUN 虚拟网卡劫持了 192.168.x.x 局域网私网段。在配置规则中添加 IP-CIDR,192.168.0.0/16,DIRECT 即可修复。
