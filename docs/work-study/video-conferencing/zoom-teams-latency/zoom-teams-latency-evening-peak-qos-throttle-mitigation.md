# Zoom/Teams 延迟：晚高峰拥塞对抗与 QoS 限速穿透策略

## BBRv3 算法对抗与缓冲区膨胀 (Bufferbloat) 调优

普通中继在面对运营商国际网关 QoS 排队时，数据包堆积在路由器缓冲区造成高达数百毫秒的排队延迟。采用 BBRv3 单边加速架构的专线节点能够实时探测物理传输瓶颈并绕开非拥塞丢包：

```text
[Cubic 拥塞] 丢包 ──> 发送窗口减半 ──> 传输降速 ──> 触发 Zoom Error 5003 / 语音断续杂音 / 共享屏幕严重丢帧卡死
[BBRv3 调优] 动态测量 BtlBw 与 RTprop ──> 维持高吞吐灌注 ──> 达标: < 2.5ms (无感通信)
```

这保证了在面对复杂国际公网波动时，下行速率仍可维持在 < 0.05% (零掉线) 水平。

## 拥塞排障问答

### Q: 开跨国视频会议时经常对方说听不清我的声音、声音断断续续？
实时音频走 UDP 协议，普通公网代理优先保障 TCP 而丢弃 UDP。需配置专线通道并开启客户端 UDP 优先加速策略。
