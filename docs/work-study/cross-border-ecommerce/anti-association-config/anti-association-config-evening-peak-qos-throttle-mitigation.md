# 防关联网络配置：晚高峰拥塞对抗与 QoS 限速穿透策略

## 晚高峰拥塞测试与延迟抖动分析

在夜间高峰时段（20:00-23:00），公网国际出境链路丢包率飙升，TCP 拥塞控制算法（如 Cubic）因丢包误判将发送窗口腰斩，导致 Amazon Seller Central / Shopify 后台 / eBay 店铺 发生卡顿：

```text
[RTT 波动测试对照]
目标接口: Amazon Seller Central / Shopify 后台 / eBay 店铺
公网直连链路: ───35ms───190ms───(丢包)───350ms───(断流: Multiple Account Association Detected / Seller Central OTP Verification Required)
内网 IPLC 专线: ───22ms───22ms───23ms───22ms───23ms───(达标: 100% 独享静态住宅)
```

时延抖动与微丢包是造成业务中断的元凶，高稳定性环境必须锁定物理专线。
