# 极速缓冲优化：分流规则编排与节点协议参数调优指南

## Sing-box 现代 JSON 出站路由规则映射

若客户端选用 Sing-box 内核，可将分流规则编排为原生的 Outbound Route 规则项，杜绝策略冲突：

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": ["youtube.com"],
        "outbound": "proxy-dedicated"
      },
      {
        "geoip": "cn",
        "outbound": "direct"
      }
    ]
  }
}
```

## 内核参数优化实录

```yaml
# YouTube 极速缓冲策略
proxy-groups:
  - name: YOUTUBE-SPEED
    type: url-test
    url: http://www.gstatic.com/generate_204
    interval: 300
    proxies:
      - 飞猫云-极速节点
      - 光速云-大带宽专线
```

通过将出口流量锁定至独立策略，避免与日常国内流量发生抢占。
