# Apple TV 配置：静态原生住宅 ISP 辨识与欺诈分深度审计

## 广播 IP 与原生住宅宽带的本质差异

许多廉价公网节点虽然在测速工具中显示为海外归属地，但底层 ASN 登记为数据中心托管（Hosting）。目标服务端在处理 Apple TV 4K / Google TV / 索尼/小米智能电视盒子 请求时，会实时查询 MaxMind GeoIP2 库，一旦检测到机房 IP，直接提升风险系数至拒绝阈值。

```text
[机房托管 IP (Hosting)] ──> IPinfo 标注: type: hosting ──> 判定为云服务器/爬虫代理 ──> 触发 TV 客户端无法导入订阅 / 遥控器无法操作配置 / 局域网分流失效
[原生住宅 IP (ISP)]     ──> IPinfo 标注: type: isp     ──> 判定为当地居民真实家庭宽带 ──> 原生放行 (365 天无感自愈运行)
```

---

## 节点信誉快速检测指令

```bash
# 查询当前出口节点 ASN 类型与欺诈评分
ping 192.168.1.100 && curl -I http://192.168.1.100:9090
```

若返回的 `org` 或 `as_name` 包含 Hosting 字样，说明为典型机房 IP，无法用于高风控业务。

## 节点属性问答

### Q: Apple TV 无法安装单独代理软件，如何实现全屋无感翻墙？
在局域网部署软路由透明网关（Passwall/OpenClash）或在 Apple TV tvOS 上直接运行 Surge/Sing-box 作为旁路网关。
