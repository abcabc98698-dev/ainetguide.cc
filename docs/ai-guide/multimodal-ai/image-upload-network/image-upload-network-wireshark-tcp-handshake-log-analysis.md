# 图片上传网络：Wireshark 抓包与 TCP 三次握手底层复盘

## Wireshark 报文跟踪与时序重现

在复现 **Discord Image Upload Failed / WebRTC Audio Jitter Buffer Drop (Voice Stutter)** 故障时，我们捕获到了以下关键网络帧：

```text
No.  Time     Source           Destination      Protocol Length Info
01   0.000    192.168.1.100    Remote Server    TCP      66     [SYN] Seq=0 Win=64240
02   0.045    Remote Server    192.168.1.100    TCP      66     [SYN, ACK] Seq=0 Ack=1
03   0.046    192.168.1.100    Remote Server    TCP      54     [ACK] Seq=1 Ack=1
04   0.052    192.168.1.100    Remote Server    TLSv1.3  512    Client Hello (Midjourney / DALL-E 3 / ChatGPT 高级语音对话)
05   0.078    Remote Gateway   192.168.1.100    TCP      54     [RST, ACK] Seq=1 Ack=513
```

报文第 05 帧的 `[RST, ACK]` 明确指示：中间防火墙或边缘 WAF 在检测到 Client Hello 中的明文 SNI 或指纹特征后，下发了强制断流包。

## 协议指纹与加密绕过方案

现代安全审计引擎通过比对 TLS JA4 指纹判断客户端合法性。普通代理因缺少 uTLS 模拟容易暴露指纹，导致平台识别。

### 现场验证与抓包重试指令
```bash
traceroute -U -p 50000 1.1.1.1
```

### 部署加密对抗与分流规则
```yaml
# 开启 uTLS 伪装与抗阻断配置
tls:
  reality: true
  sni: midjourney.com
rules:
- DOMAIN-SUFFIX,midjourney.com,AI-SERVICES
- DOMAIN-SUFFIX,discord.com,AI-SERVICES
- DOMAIN-SUFFIX,suno.ai,AI-SERVICES
- DOMAIN-SUFFIX,runwayml.com,AI-SERVICES
```
