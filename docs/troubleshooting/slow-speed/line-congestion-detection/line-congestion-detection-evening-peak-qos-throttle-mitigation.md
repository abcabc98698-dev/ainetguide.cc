# 线路拥堵检测：晚高峰拥塞对抗与 QoS 限速穿透策略

## BBRv3 算法对抗与缓冲区膨胀 (Bufferbloat) 调优

普通中继在面对运营商国际网关 QoS 排队时，数据包堆积在路由器缓冲区造成高达数百毫秒的排队延迟。采用 BBRv3 单边加速架构的专线节点能够实时探测物理传输瓶颈并绕开非拥塞丢包：

```text
[Cubic 拥塞] 丢包 ──> 发送窗口减半 ──> 传输降速 ──> 触发 DNS Pollution / System Proxy Conflict / TUN Driver Failed / Loopback Error
[BBRv3 调优] 动态测量 BtlBw 与 RTprop ──> 维持高吞吐灌注 ──> 达标: 100% 恢复正常通信
```

这保证了在面对复杂国际公网波动时，下行速率仍可维持在 DoH / Fake-IP 零污染 水平。

## 拥塞排障问答

### Q: 日常测速飞快，一到晚上特定时间就断流丢包严重？
公网国际出口链路拥塞所致。在客户端开启协议多路复用（Multiplexing）与拥塞控制算法调优（BBR），或切换为全 IPLC 专线。
