# 浏览器缓存：分流规则编排与节点协议参数调优指南

## Sing-box 现代 JSON 出站路由规则映射

若客户端选用 Sing-box 内核，可将分流规则编排为原生的 Outbound Route 规则项，杜绝策略冲突：

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": [".com"],
        "outbound": "proxy-dedicated"
      },
      {
        "geoip": "cn",
        "outbound": "direct"
      }
    ]
  }
}
```

## 策略编排要点问答

### Q: 只要一登录海外账号就要求手机短信二次验证，频繁被提示异地登录？
客户端节点配置了自动负载均衡（Round-Robin），导致短时间内出口 IP 频繁跨国漂移。务必将特定站点绑定至固定专线节点。
