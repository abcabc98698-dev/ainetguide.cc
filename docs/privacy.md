# 隐私政策 (Privacy Policy)

> **生效日期**：2026-10-26  
> **更新时间**：2026-10-26

**ainetguide.cc（跨境网络与 AI 办公指南）**（以下简称“本站”或“我们”）深知网络隐私与数据安全对每位用户的重要性。本隐私政策旨在向您说明我们在您访问本站时如何收集、使用、存储及保护您的信息。

---

## 核心原则：零日志、不刺探、不追踪

1. **我们不提供代理服务本身**：本站为纯静态的开源技术知识库与行业信息导航站。本站服务器不充当任何用户的 VPN、代理中继或数据转发网关。
2. **零流量审查**：我们无法、也不会拦截、审查、记录或解密您通过任何第三方客户端（Clash、Sing-box 等）发起的网络通信数据包。
3. **极简统计**：本站仅使用隐私友好的轻量级无 Cookie 访问统计，仅用于评估技术文章阅读量与排障指南的有效性，绝不采集您的真实 IP、设备硬件指纹或跨站行为轨迹。

---

## 我们收集与处理的信息范围

### 1. 匿名基础访问日志 (Server Access Logs)
当您通过浏览器访问本站页面时，托管基础设施（如 Cloudflare / Vercel CDN）可能会出于网络安全防护（如拦截 DDoS 攻击、识别恶意 CC 爬虫）的必要目的，生成临时匿名访问日志，包含：
- 请求的 URL 路径与时间戳；
- 浏览器 User-Agent 字符串（用于自适应移动端与桌面端渲染）；
- 脱敏处理后的 IP 段。

这些临时日志仅在内存中保留极短周期（通常不超过 72 小时），并在安全审计后自动覆盖销毁。

### 2. 用户主动反馈信息
若您通过电子邮件（`contact@ainetguide.cc`）向我们提交技术勘误、节点报错或合作意向，我们仅保留您自愿提供的邮箱地址与邮件正文，仅用于与您沟通问题处理进展，绝不向任何第三方商业机构出售或共享。

### 3. 本地存储 (Local Storage)
本站前端使用浏览器的本地存储（Local Storage）仅用于保存您的界面偏好设置（例如深色/浅色主题切换模式、字体大小调节）。这些数据仅保存在您的个人终端本地，不会同步至任何远程服务器。

## 第三方外部链接与商业联盟披露

1. **外部网站跳转**：本站包含指向第三方服务商官网、GitHub 开源代码仓库及官方软件下载站的链接。一旦您点击链接离开 ainetguide.cc，您的浏览行为将受目标网站的隐私政策管辖。我们强烈建议您在注册任何第三方服务前审阅其用户协议与隐私条款。
2. **赞助链接与 Cookies**：部分评测文章中包含第三方商家的联盟推荐链接（Affiliate Links）。当您点击此类链接时，目标商家可能会在其域名下放置追踪 Cookie，用于确认该次访问由本站引流。该过程由商家系统独立运作，本站无法读取您的个人财务信息、账号密码或信用卡信息。

---

## 数据安全保护措施

- **全站强制 TLS 1.3 传输加密**：所有访问均通过现代密码学算法（ECDSA / AES-256-GCM）进行端到端加密，杜绝任何中间人嗅探与运营商 HTTP 劫持。
- **安全响应头加固**：生产环境部署包含严格的 `Content-Security-Policy`、`X-Frame-Options: SAMEORIGIN` 与 `X-Content-Type-Options: nosniff` 规则，防止跨站脚本（XSS）与点击劫持。

## 政策修订与隐私权利

我们可能根据技术架构演进或法律法规要求适时修订本政策。所有修改均将在本页面即时公布并更新生效日期。

若您对个人数据有任何疑问或主张，欢迎通过 `contact@ainetguide.cc` 与我们的隐私合规团队联系。
