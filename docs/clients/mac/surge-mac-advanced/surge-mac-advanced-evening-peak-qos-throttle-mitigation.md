# Surge：晚高峰拥塞对抗与 QoS 限速穿透策略

## 晚高峰拥塞测试与延迟抖动分析

在夜间高峰时段（20:00-23:00），公网国际出境链路丢包率飙升，TCP 拥塞控制算法（如 Cubic）因丢包误判将发送窗口腰斩，导致 跨平台客户端配置与内核优化 发生卡顿：

```text
[RTT 波动测试对照]
目标接口: 跨平台客户端配置与内核优化
公网直连链路: ───35ms───190ms───(丢包)───350ms───(断流: Core Process Terminated / Helper Permission Denied / Rule Syntax Error)
内网 IPLC 专线: ───22ms───22ms───23ms───22ms───23ms───(达标: < 65 MB)
```

时延抖动与微丢包是造成业务中断的元凶，高稳定性环境必须锁定物理专线。

## 拥塞排障问答

### Q: Mac 休眠唤醒后无法上网，必须重启代理软件？
macOS 电源管理在休眠时断开了代理辅助工具（Helper Tool）IPC 管道。在设置中开启自动重连守护即可。
