# 免折腾配置：风控模型逆向拆解与多开防关联沙盒方案

## 风控决策模型逆向拆解

对于 新手零门槛一键客户端与免折腾配置，服务商的安全引擎根据以下矩阵进行实时信誉打分：

```text
[入站请求] ──> [ASN 类型校验: 是否为机房 Hosting?] ──> 若是，欺诈分 +50 分!
                 │
                 ├──> [WebRTC 穿透检测: 真实网卡 IP 是否泄露?] ──> 若是，直接熔断!
                 │
                 └──> [TLS JA4 握手特征: 是否为非常规脚本指纹?] ──> 若是，返回 Complex YAML Config Syntax Error / Subscription Import Failed!
```

只有当所有信誉检测项均通过，且 IP 属于当地真实住宅宽带（Residential ISP）时，系统才会开放完整的业务权限。

## 沙盒防风控三步落地实操

### 1. 验证节点纯净度
在连接 新手零门槛一键客户端与免折腾配置 前，执行探测命令排查 IP 属性：
```bash

```

### 2. 封堵 WebRTC 泄露
在浏览器或客户端规则中添加阻断 STUN 端口的指令：
```yaml
rules:
- DOMAIN-SUFFIX,ainetguide.cc,AI-SERVICES
```
